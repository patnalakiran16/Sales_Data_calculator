Sales Data Calculator

Project Overview

The Sales Data Calculator is a simple Python project that analyses a list of sales values and calculates basic sales statistics. It helps understand how Python can be used for basic numerical data analysis.

Objective

To calculate the total sales, average sales, highest sale, and lowest sale using Python.

Technologies Used

- Python
- Jupyter Notebook

Features

- Stores sales values in a Python list.
- Calculates total sales using "sum()".
- Calculates average sales using "len()".
- Finds the highest sale using "max()".
- Finds the lowest sale using "min()".
- Displays the results in a readable format.

Sample Sales Data

sales = [1500, 2500, 1800, 3200, 4000, 2200, 3500]

Output

All Sales: [1500, 2500, 1800, 3200, 4000, 2200, 3500]
Total Sales: 18700
Average Sales: 2671.43
Highest Sale: 4000
Lowest Sale: 1500

How to Run the Project

1. Install Python on your computer.
2. Install Jupyter Notebook using "pip install notebook".
3. Open Jupyter Notebook.
4. Create a new Python notebook.
5. Copy the project code into a cell.
6. Run the cell to view the sales analysis results.

Key Learnings

- Working with Python lists.
- Using built-in functions such as "sum()", "len()", "max()", and "min()".
- Performing basic mathematical calculations.
- Displaying results using "print()".
- Understanding basic sales data analysis.

Conclusion

This project demonstrates how Python can be used to perform basic sales data analysis efficiently. It is a beginner-friendly project that builds a foundation for more advanced data analysis tasks.
